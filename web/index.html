Zolal core browser demo

Your files and passphrase never leave your device. Hiding and revealing run entirely in your browser; we don't receive or store anything. Once the page has loaded it keeps working with the internet switched off, and after one visit it also opens offline. (The page itself is served by GitHub Pages, which, like any web host, sees that the page was requested.)

Demo only. This is a simple front end for the engine, not the audited app. Don't use it for real secrets.
